1 Detailed Project Overview

Zylarium is a large-scale website that works like an entire desktop computer program inside your browser. Instead of making users download messy software or pay expensive monthly fees for tools they only use sometimes, Zylarium provides an enormous library of utilities instantly for free.

The visual design of the website uses a "Liquid Glass" theme. This means backgrounds are dark, elements are slightly transparent so you can see blurred colors behind them, and text uses sharp, glowing highlights to draw attention to important information.

2 Why Zylarium Exists

Many websites on the internet try to exploit regular users. If you want to merge two PDF files, a search usually takes you to a site filled with confusing buttons, heavy advertisements, and a hidden subscription fee. Even worse, many sites force you to upload your private business documents or personal identification photos to their servers to process them, creating a massive security risk.

The Solution: Zylarium was built to reverse this trend. The goal is to provide beautiful, fast, and totally free tools that process everything locally on the user's computer. It brings together designers, programmers, freelancers, and normal computer users into one reliable workspace.

3 Core Rules and Boundaries

  • Rule 1: Client-Side Safety Guarantee. When a user clicks a button to convert a file or process an image, the website's javascript code must do the heavy lifting in the browser memory. The website will never secretly upload the file to a remote server.
  • Rule 2: Stunning Visuals over Boring Utility. People associate free internet tools with ugly design. Zylarium must feel like a premium paid application. Animations must be smooth, components must fade in gently, and buttons must react cleanly when hovered over.
  • Rule 3: Simple Vocabulary. The website should not use complex engineering jargon on the front-end interface, so that everyday users can quickly understand what a tool does.

4 The File & Folder Architecture Explained

To understand Zylarium, you must understand exactly how the project folders are built. Below is a highly detailed explanation of every folder and what role it plays in making the website work.

The Main Folders

/src/pages/

This folder is where the massive, whole-screen pages live. When you click a link on the top menu of the website, the application loads one of the files from this folder.

  • Home.tsx: The beautiful hero screen you see first. It has the glowing title, the parallax scrolling features, and the links to the main five sections.
  • Unitoolbox.tsx: The massive library page. It builds the layout showing the search bar, category filters, and the grid of 30+ clicking tool cards.
  • HustleFinder.tsx: The freelance job directory page. This builds the dual-column layout where the search and checkbox filters sit on the left, and the job cards appear on the right.
  • FinanceTools.tsx: The money dashboard. This page builds the colorful pie charts showing budget data and the large loan calculator.
  • CodeXRay.tsx: The developer center. This builds the interface for all the advanced code architecture mapping systems.
/src/components/

This folder is enormous. It does not hold entire pages, but rather the small "building blocks" that create the pages. If a page is a house, this folder holds the doors, windows, and bricks.

  • Layout.tsx & CommonUI.tsx: These hold the standard buttons, input boxes, and the main website wrapper (the navigation bar at the top and the footer at the bottom). We reuse these everywhere so the website design stays perfectly consistent.
  • /src/pages/components/ (Inside Unitoolbox): This is incredibly important. Every single one of the 30+ tools in UniToolbox has its own unique .tsx file here. When you click the "Image Compressor" card, the website fetches the specific ImageCompressor.tsx file to display the upload box and sliders on your screen.
  • /src/components/resume/: Contains all the specific blocks for building a resume, like the "Experience field" input forms or the "Education field" forms.
  • /src/components/codexray/: Contains the complex diagram blocks used by the developer tools section.
/src/services/

This folder contains the "connecting cables" that talk to the outside world.

  • geminiService.ts: This specific file holds the instructions for talking to Google's artificial intelligence. If a user wants to summarize a book, the website uses this file to package the text, send it securely to Google's brain, and bring the summary back to the screen.
/src/data/ & /src/store/

These folders handle information logic.

  • hustleData.ts: A file packed with writing. It contains the raw job descriptions, required skills, and estimated earnings for all 120+ side hustles shown in the HustleFinder.
  • State Management (Store): Contains logic to remember what the user is doing. For example, remembering which tab a user is looking at without reloading the web page.
Root Base Files

The files that sit at the absolute bottom of the project and make everything run.

  • index.html: The absolute foundational blank canvas of the website.
  • App.tsx: The traffic controller. It tells the browser "If the user visits the address '/unitoolbox', load the Unitoolbox.tsx page file."
  • index.css: The styling heartbeat. This file holds hundreds of lines of visual code that defines exactly what color the "primary" purple is, how fast the fade-in animations take to execute, and how the glowing liquid glass backgrounds are painted.
  • package.json: The instruction manual for the computer. It lists every external library the project needs (like React, Tailwind, Framer Motion) so another developer can download and run the project easily.

5 Module 1: UniToolBox (Every Tool Detailed)

UniToolbox is the giant grid of small utility programs. Here is exactly what every single tool does, how it functions for the user, and how it is built under the surface.

Text & Artificial Intelligence Tools

1. AI Essay Summarizer

  • Functionality: A user copies and pastes a massive wall of text into a text box and clicks "Summarize". The screen presents a short, bulleted list of the main points.
  • How it works under the hood: The tool takes the text from the input box, formats it into a specific prompt, and sends it to the geminiService.ts file. This service securely queries Google's AI model with instructions to condense the text. The website waits for the reply and prints it on the screen.

2. AI Language Translator

  • Functionality: Similar to Google Translate. Type text in one box, choose a target language, and receive the translation instantly.
  • How it works under the hood: Also routes through the Gemini AI service, passing explicit system instructions to act as a highly accurate language interpreter rather than a conversational chat robot.

3. AI Book Summary

  • Functionality: Users can upload entire document files (PDFs or Word docs) instead of just pasting text. The tool reads the file and outputs an intelligent summary of the chapters.
  • How it works under the hood: It utilizes the pdfjs-dist library to open the PDF file locally in the browser memory, scans through the pages to extract raw text characters, chunks the text into manageable pieces, and feeds it to the AI summarizer.

4. ASCII to Text

  • Functionality: A simple decoding tool. Paste computer numbers (like 01001000 01101001) and it outputs the human language equivalent (like "Hi").
  • How it works under the hood: Uses pure, native Javascript string manipulation functions. It splits the numbers by spaces, reads their binary or hexadecimal value, and converts them to standard characters in milliseconds without any outside APIs.

5. Text to Handwriting

  • Functionality: You type an essay into a box. The screen shows a preview of a piece of notebook paper where your essay looks like it was written by a human hand using blue ink. You can download the image.
  • How it works under the hood: The tool uses the HTML5 <canvas> element. It draws a picture of lined notebook paper in the background. Then, using specialized downloaded fonts (like 'Caveat' or 'Dancing Script'), it draws the user's text on top of the paper lines. The html2canvas library then saves the canvas as a downloadable PNG picture.

6. AI Voice Notes

  • Functionality: Upload an audio recording. The tool listens and writes down everything said into a clean document.
  • How it works under the hood: Uses browser APIs and AI transcription services to decode the audio waveform into recognizable speech strings, format them properly, and present them in a text box.

Image Tools

7. Image Compressor

  • Functionality: Upload a massive, 5 Megabyte photograph. A slider lets you pick the desired quality. It instantly provides a new, visually identical photograph that is only 500 Kilobytes in size, making it much faster to email or upload.
  • How it works under the hood: It loads the image into a hidden HTML5 canvas. When the user changes the quality slider, the script commands the canvas to export the image data (using canvas.toDataURL('image/jpeg', qualityValue)). It calculates the math to show the exact size reduction on the screen.

8. Image Resizer

  • Functionality: Allows a user to stretch or shrink an image's pixel dimensions exactly (for example, turning a 1920x1080 wallpaper into a 500x500 square).
  • How it works under the hood: The image is drawn onto an invisible canvas sized exactly to the user's newly requested width and height. Javascript then mathematically scales the image pixels to fit the new box and exports the picture.

9. Background Remover

  • Functionality: Click on a picture of a person standing outside. After processing, the background disappears, leaving only the person cut out perfectly on a transparent background.
  • How it works under the hood: Because advanced background removal is incredibly difficult for standard browsers to do mathematically, it often hooks into a lightweight client-side machine learning model (like TensorFlow.js) that specifically identifies human silhouettes and clears surrounding pixel values to "transparent".

10. Image to Text (OCR)

  • Functionality: Upload a picture of a street sign or a printed document. The tool extracts all the readable words from the picture into a copy-pasteable text box.
  • How it works under the hood: It runs the tesseract.js library. This is an optical character recognition engine that scans the contrast of pixels in the image to recognize shapes of letters, matching them to an alphabet database loaded in the browser.

11. Image to Icon

  • Functionality: Upload a logo image, and instantly receive appropriately trimmed and squared .ico files perfect for website browser tabs.
  • How it works under the hood: Shrinks the image onto a series of very small canvas boxes (like 16x16, 32x32 pixels) and exports the raw data formatted with a specific icon file extension.

12. Passport Photo Gen

  • Functionality: Upload a selfie. The tool places an oval frame over the picture, allows the user to align their face perfectly, and spits out a 2x2 inch printable photo sheet.
  • How it works under the hood: A highly structured canvas interface. It acts like a window. It measures the exact mathematical ratio required for government photos, crops out anything outside the window, and draws that cropped face repeatedly on a larger canvas simulating a 4x6 photo paper size.

Document & Data Tools

13. & 14. PDF to Word / Word to PDF

  • Functionality: Changes files from uneditable PDF layouts to editable typed Word documents, and vice versa.
  • How it works under the hood: A very difficult process. Converting Word to PDF involves deeply reading the .docx internal XML structure to find paragraphs and fonts, then drawing those elements identically using the pdf-lib library to create a solid document.

15. Text to PDF

  • Functionality: Type into a blank box, click a button, and get a clean PDF document back.
  • How it works under the hood: The javascript loads a blank PDF page object into memory, measures the width of the user's typed sentences, wraps the text so it does not run off the side of the page, and draws the letters onto the PDF object before triggering a download.

16. Password Protect PDF

  • Functionality: Upload an unprotected PDF, type a strong password twice, and receive a new locked PDF that asks for a password whenever anyone tries to open it.
  • How it works under the hood: Traditional browsers are currently very bad at the extremely heavy mathematics required to securely encrypt massive files. Therefore, this tool sends the file to a lightning-fast "Cloudflare Worker" (a serverless computer cluster on the edge of the internet). The Cloudflare worker locks the file using AES-256 military-style encryption and hands it straight back.

17. Image to PDF

  • Functionality: Select five different photographs and click combine. You receive one single PDF file with five pages, where each page is one of the photographs.
  • How it works under the hood: The pdf-lib tool creates a blank book. It loops through the photographs, measures them, creates a blank page for each one exactly that size, embeds the image data onto the fresh page, and saves the book.

18. PDF to Image

  • Functionality: Upload a 10-page PDF document. Receive a ZIP folder containing 10 high-quality PNG pictures of those pages.
  • How it works under the hood: Uses pdfjs-dist. It commands the browser to quietly render the PDF page visibly onto a hidden canvas element, exactly as a human would see it. Then, it snaps a picture of that canvas, repeats for every page, bundles the pictures using the jszip library, and triggers the download.

19. PDF Compressor

  • Functionality: Shrinks the megabyte size of a heavy PDF.
  • How it works under the hood: It scans the entire PDF code to find embedded images and reduces their quality slightly, while also erasing invisible wasted data (like hidden layers or unused fonts) from the file structure without damaging the text.

20. & 21. PDF Splitter / PDF Merger

  • Functionality: Chops pages out of a book, or glues two books together to make a bigger one.
  • How it works under the hood: The code opens both files in memory. For merging, it simply copies the page objects from the second book and appends them to the end of the array of pages in the first book, exactly like shuffling cards.

Media Tools

22. Pro Video Compressor

  • Functionality: Uploads an MP4 video, lowers the quality slightly, and provides a smaller file size download.
  • How it works under the hood: Runs FFmpeg directly inside the web browser using a powerful technology called WebAssembly. It mathematically crunches the video frames to lower the bitrate without needing a server.

23. Video to GIF Pro

  • Functionality: Turns a short video clip into a repeating, silent animation (a GIF).
  • How it works under the hood: Extracts all individual picture frames from the video and compiles them strictly into the GIF file format structure using browser memory.

24., 25. & 26. Resolution Changer, Format Converter, Rotator

  • Functionality: Stretches video size, changes formats, or fixes a video recorded upside down.
  • How it works under the hood: All utilize the WebAssembly FFmpeg engine to rebuild the video file based on strict command-line style arguments processed directly by the client's CPU.

Converter Tools

27., 28., 29. & 30. Format Converters (WebP to JPG, PNG to SVG, etc.)

  • Functionality: Changes images from one file type to another to ensure compatibility with different websites or software.
  • How it works under the hood: Relies on the HTML5 Canvas trick. Draw a WebP image onto the canvas, but ask the canvas to export it as a JPG. The browser handles the complex format translation natively, instantly giving the user the new file.

Utilities

31. Unit Converter

  • Functionality: Changes values (Miles to Kilometers, Pounds to Kilograms).
  • How it works under the hood: Simple math dictionaries built into Javascript. Multiplies the input number by a strict, pre-defined mathematical constant based on user dropdown selection.

32. Advanced Calculator

  • Functionality: A scientific calculator interface keeping a history of equations.
  • How it works under the hood: Uses the mathjs library to securely and accurately evaluate complex mathematical strings (like parsing "sin(45) * log(10)") without accidentally processing harmful code.

33. & 34. Password Generator & Strength Checker

  • Functionality: Creates a totally random string of letters and symbols, and judges how good passwords are.
  • How it works under the hood: Uses cryptographic randomness tools built into the browser (crypto.getRandomValues()) to guarantee the password is mathematically unpredictable. The checker uses complex regular expressions (Regex) to scan the string and award a point score based on length and character variation.

6 Module 2: HustleFinder Features

HustleFinder is a beautiful data catalog designed to help users browse 120+ verified side hustles.

The Interface Anatomy

  • The Header: A massive title section featuring animated numbers noting exactly how many total jobs are in the database.
  • The Left Filter Panel: An always-visible (on large screens) command center. It offers tick boxes categorized nicely. A user can tick "Beginner Friendly", and the react state instantly hides all Advanced jobs without reloading the webpage.
  • The Job Cards: Glass-styled cards representing a job. They contain badges mapping out the difficulty, a bold title, a short description, the exact estimated earning potential in green, and a list of required skills.

The Storage Mechanic (Favorites)

Every single job card has a small star icon. When a user clicks the star, the system triggers a micro-animation (it scales up and down briefly) and turns it yellow.

Behind the scenes, the javascript grabs the unique ID number of that job (say, Job ID #45), packages it into a tiny JSON string, and shoves it into the browser's localStorage API. Tomorrow, when the user launches the website again, the code first peers into localStorage, sees "ID #45", matches it to the database, and repaints that star yellow immediately. Clicking the top "Show Saved" button simply commands the code to format the grid using only the IDs found in that local storage box.

7 Module 3: Finance Tools Dashboard

This module provides immediate visual clarity for personal wealth tracking.

The Dashboard Charts

When clicking the Dashboard tab, the user sees high-end KPI (Key Performance Indicator) cards showing Total Balance and Monthly Savings. Below these are two major visual components powered by the recharts library:

  • The Monthly Expenses Pie Chart: It takes an array of data (Rent: 1200, Food: 400) and feeds it to the Recharts engine. The engine mathematically calculates the angles for a circle and draws brightly colored, sweeping SVG curves to create a stunning, hoverable donut chart.
  • The Net Worth Trend Line: Feeds historical data points onto an X-Y axis. The line chart curves smoothly between money points, creating a professional financial growth graph entirely formatted completely client-side.

The EMI Calculator Mechanics

The layout features three primary input sliders: Loan Amount, Interest Rate, and Tenure (Years). The moment a user clicks and drags any of these sliders by even a millimeter, the React framework kicks in.

Every small movement updates a local variable state. The page immediately asks a master formula equation to run using those numbers: (Principal * rate * (1+rate)^time) / ((1+rate)^time - 1).

The result is instantly printed large on the right side of the screen, breaking down the exact monthly payment and total bank interest cut in giant text, making complicated bank math totally transparent and easy to visualize.

8 Module 4: Code X-Ray System

Code X-Ray is a heavy, professional-grade module reserved specifically for software developers wanting to understand large computer programs.

The Complex Tools Inside

  • Interactive Architecture Map: You upload a massive folder of code files. Javascript scans every file, hunting for the word "import". It draws a relationship web—a spiderweb map—where every file is a glowing bubble, connecting lines to other files that depend on it.
  • Code Usage Finder: A highly aggressive search engine. You type a function name, and it rapidly combs through thousands of lines of text inside the browser memory to highlight exactly where and how that function is implemented elsewhere in the project.
  • Dead Code Detector: Utilizing logic similar to an architecture map, if it finds a file bubble that has absolutely zero connecting lines pointing to it from anywhere else in the project, it flags it as "Dead Code" that can be safely deleted.

How it was made: To prevent extreme memory crashes, this section uses a React technique called "Lazy Loading". The heavy code maps only download and compute exactly when the user clicks explicitly onto them, leaving the main homepage fast and light.

9 Module 5: Resume Builder Workflow

This module exists to ensure users can produce a gorgeous, professional job resume without fighting with Microsoft Word templates.

The Left-Right Live Preview Design

The screen is split perfectly in half. On the left side are clean, clear input boxes (Name, Phone Number, Work History). On the right side is a live, glowing sheet of paper.

Because it is built with React, the moment a user presses a single key on their keyboard in the "Name" box on the left, that exact letter flashes and appears on the resume paper on the right simultaneously. The layout is pixel-perfect and mathematically rigid, refusing to let the user accidentally drag a text box off alignment.

The AI Ghost Writer

Inside the Work History box is an "AI Assist" button. Often, people struggle to describe a past job professionally. A user can type "I sold shoes and stocked shelves." Pressing AI Assist packages that bad sentence, sends it to the Gemini module, and returns: "Managed high-volume retail transactions while executing inventory logistics and merchandising strategies." It upgrades the user's language instantly.

The Final PDF Engine

When completed, clicking "Download" does not just take a blurry screenshot. It runs a complex HTML-to-PDF compiler that meticulously translates the exact visual styling (spacing, fonts, borders) onto a vector-based Adobe PDF file, ensuring printers construct the ink perfectly sharply.

10 Verification Checklist

To ensure Zylarium remains a premium, high-end application, developers must run through this intense checklist before any update is published.

  • The Visual Stress Test: Open the tool on a massive 4K monitor. Ensure the parallax tool grid gracefully scales out to 3 or 4 columns wide, filling empty space without breaking the glass borders. Verify glowing orbs behind the glass stay positioned correctly.
  • The Typography Inspection: Ensure secondary headers strictly follow the "font-signature" rule (the cursive styling highlighting specific words in cyan and purple). No raw system fonts are allowed to show.
  • The Disconnected Airplane Mode Test: Shut off the computer's Wi-Fi. Enter the Unitoolbox and attempt to compress a large JPG image. If the tool displays an "Offline Error", the code architecture has failed. Image compression must successfully complete entirely offline.
  • The Heavy File Chokehold: Feed the AI Essay Summarizer an outrageously long string of text (e.g., 50,000 words). Ensure the system does not crash or freeze the browser layout, but properly handles the API limitation error messaging safely and displays a soft warning to the user.
  • The Filter Math Check: In Hustlefinder, check all three difficulty boxes (Beginner, Intermediate, Advanced) simultaneously. Ensure the math calculation displays correctly that 100% of the entire database is shown, rather than confusing the filtering logic.
